{%- comment -%} The shell of each HTML page of the site, except the login page and the store redirect (_layouts/login.html and _layouts/store.html): the head, the nav, the content in `main`, the closing band with the footer, and the scripts. The head links the stylesheet, /assets/css/site.css (see _includes/head.html and assets/css/site.scss). A layout for one kind of page (for example _layouts/press.html) sets `layout: base` and wraps its content. A page or a layout can set these keys in its front matter: bodyClass The class of the body, for example `mt-press-page`. sectionChrome true: the toolbar and the status bar of the browser take the colour of the section at the top edge of the viewport. Use it for a page with a dark hero. See the script at the end of this file. ogImage The share image of the page. See _includes/head.html. platformNav true: shows the platform bar under the nav. The bar has links to the four landing pages: Home, iPhone & iPad, Mac, and iPhone Duo. Set it on those pages and on no other page. See _includes/platform-nav.html. closingBlurb The text under the title of the closing band, in place of the default text. See _includes/closing.html.
