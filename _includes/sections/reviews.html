{%- comment -%} The "Loved on the App Store" section: App Store reviews, in cards. A review with an `image` in _data/reviews.js is a picture, a card of the review that the user made, with a light version and a dark version (900 x 1200, the files of the home/review- rows of tools/site-assets.tsv). The images are @3x: a card is 300px wide (18.75rem), and the 900px file is for a screen of 3x. The words of the review are in the alt text of the picture. A review without an image is a card with the quote, the name of the reviewer, and "App Store". The quotes are in _data/reviews.js. A quote shows only when its entry has `use: true`. The file says how to approve a quote. When no entry has `use: true`, this file writes nothing: no section, no heading, and no empty space. The styles are in _sass/site/_sections.scss. The data is global, but `render` does not see it. Pass it: {% render "sections/reviews.html", reviews: reviews %} {% render "sections/reviews.html", reviews: reviews, tone: "tint" %} Parameters: reviews The list of reviews: `reviews` from _data/reviews.js. tone Optional. The background of the section: "plain" (the default) or "tint". Choose the one that differs from the sections above and below it. {%- endcomment -%} {%- assign approvedReviews = reviews | where: "use", true -%} {%- if approvedReviews.size > 0 -%}
